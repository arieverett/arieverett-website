# Ari Everett website — Super-style reconstruction

This is the self-hosted version based on the HTML Notion export and the mobile and desktop screenshots. The homepage design has been rebuilt to closely follow the live site rather than the earlier redesigned starter. The six writing/portfolio detail pages and images page are preserved from the previous export.

## Preview
Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000.

## Deployment
See MIGRATION.md. Do not change DNS or cancel Super until you are satisfied with the preview and have tested the deployment.

This is a visual recreation based on screenshots, not the proprietary Super source or an identical pixel-for-pixel capture.
